# Устранение неполадок

## Виджет сообщает «Codex не найден»

Проверьте CLI в новом окне PowerShell:

```powershell
codex --version
```

Если команда не найдена, установите Codex CLI по [официальной инструкции](https://developers.openai.com/codex/cli) или добавьте его папку в пользовательский `PATH`. Монитор также проверяет стандартные папки npm, WinGet, WindowsApps, локальных программ и Windows App Paths.

Путь до `codex.exe`, `codex.cmd` или `codex.bat` можно задать явно:

```powershell
[Environment]::SetEnvironmentVariable(
    'CODEX_LIMIT_MONITOR_CODEX_PATH',
    'C:\path\to\codex.cmd',
    'User')
```

После изменения переменной полностью завершите монитор через меню в трее и запустите его снова. Неверный явный путь блокирует автоматический поиск. Чтобы вернуться к нему, удалите переопределение:

```powershell
[Environment]::SetEnvironmentVariable(
    'CODEX_LIMIT_MONITOR_CODEX_PATH',
    $null,
    'User')
```

## Нет авторизации или данных лимитов

Проверьте состояние входа:

```powershell
codex login status
```

При необходимости выполните `codex login` и завершите вход в браузере. Доступные варианты описаны в [официальной документации по авторизации](https://developers.openai.com/codex/auth). Затем убедитесь, что обычный сеанс `codex` работает, и в окне **Диагностика** монитора нажмите **Переподключить**.

Отсутствие привычного пятичасового или недельного окна само по себе не является ошибкой: сервер возвращает только доступные текущему аккаунту окна.

## Состояние APP SERVER или LIMITS ERROR

Откройте **Диагностика** через меню в трее и нажмите **Переподключить**. Если ошибка повторяется:

1. завершите монитор;
2. убедитесь, что установленная версия Codex CLI запускается и авторизована;
3. обновите Codex CLI поддерживаемым для вашей установки способом;
4. снова запустите монитор и изучите последние события диагностического журнала.

Монитор не записывает stderr App Server целиком, поэтому секретные данные из него не попадают в журнал.

## Виджет исчез

- откройте скрытые значки системного трея и щёлкните **Codex Limit Monitor**;
- если включён click-through, отключите **Пропускать клики** через меню значка в трее;
- после отключения монитора приложение автоматически переносит HUD в оставшуюся рабочую область.

## Данные устарели или идёт переподключение

Последнее успешно полученное значение намеренно остаётся на экране во время восстановления. Монитор повторно запускает локальный App Server с задержками 1, 2, 5, 10 и 30 секунд. Кнопка **Переподключить** запускает новую попытку немедленно.

## Сброс настроек

Сначала завершите приложение через меню в трее, затем удалите файл:

```powershell
Remove-Item -LiteralPath "$env:LOCALAPPDATA\CodexLimitMonitor\settings.json"
```

При следующем запуске будут созданы настройки по умолчанию. Журналы при этом сохраняются.

## Диагностический журнал

Путь:

```text
%LocalAppData%\CodexLimitMonitor\Logs\monitor.jsonl
```

Журнал ограничен одним мегабайтом и ротируется в `monitor.jsonl.previous`. Он не содержит значений лимитов и данных аккаунта; потенциальные email, bearer-токены, cookies, JWT и длинные секреты маскируются.

## Автозапуск указывает на старый путь

При обычном перемещении Portable приложение автоматически переписывает путь автозапуска после следующего ручного запуска. Если запись осталась после удаления программы, удалите её вручную:

```powershell
Remove-ItemProperty `
    -LiteralPath 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Run' `
    -Name 'Codex Limit Monitor' `
    -ErrorAction SilentlyContinue
```

## SmartScreen предупреждает о запуске

Версия 0.1.0 не подписана Authenticode. Убедитесь, что файл получен из доверенного источника, и сравните его SHA-256 со значением в соседнем файле `.sha256`. Для вычисления хеша:

```powershell
Get-FileHash -Algorithm SHA256 .\CodexLimitMonitor-Setup-0.1.0.exe
```

## Настройки остались после удаления

Это ожидаемо: Setup и Portable сохраняют настройки и журналы, чтобы обновление или повторная установка не сбрасывали конфигурацию. После удаления программы данные можно удалить отдельно:

```powershell
Remove-Item -LiteralPath "$env:LOCALAPPDATA\CodexLimitMonitor" -Recurse
```
