# Codex Limit Monitor

Нативный плавающий HUD для Windows, который показывает фактические лимиты текущего аккаунта Codex через локальный транспорт `codex app-server --stdio`.

Приложение не использует браузер, screen scraping или приватные HTTP-endpoint'ы и не извлекает токены. Проценты берутся из ответа локального Codex App Server и не записываются в диагностический журнал.

## Возможности

- динамическое отображение всех доступных окон лимитов;
- процент остатка и обратный отсчёт до сброса;
- компактный режим, прозрачность, always-on-top и click-through;
- значок в системном трее, скрытие, ручное обновление и автозапуск;
- автоматическое восстановление после разрыва связи с App Server;
- поддержка нескольких мониторов и Per-Monitor V2 DPI;
- локальная обезличенная диагностика с ротацией журнала.

## Системные требования

- Windows 10 версии 1809 или новее либо Windows 11, x64;
- установленный Codex CLI и выполненный вход в аккаунт;
- команда `codex` доступна приложению либо задана переменная `CODEX_LIMIT_MONITOR_CODEX_PATH`.

Codex CLI можно установить и авторизовать по [официальной инструкции](https://developers.openai.com/codex/cli). Поддерживаемые способы входа и команды `codex login`, `codex login status` описаны в [документации по авторизации](https://developers.openai.com/codex/auth).

Setup и Portable являются self-contained сборками: для их запуска не нужны .NET SDK и Visual Studio.

## Установка через Setup

Это рекомендуемый вариант для обычного использования.

1. Запустите `CodexLimitMonitor-0.1.0-win-x64-setup.exe`.
2. При необходимости включите создание ярлыка на рабочем столе.
3. Завершите установку и запустите приложение из меню «Пуск».

Установка выполняется только для текущего пользователя, не требует прав администратора и по умолчанию использует `%LocalAppData%\Programs\Codex Limit Monitor`. Повторный запуск более новой версии Setup обновляет приложение на месте и сохраняет пользовательские настройки.

## Запуск Portable

1. Распакуйте `CodexLimitMonitor-0.1.0-win-x64.zip` в любую постоянную папку с правом записи.
2. При желании сравните SHA-256 архива со значением в соседнем файле `.sha256`.
3. Запустите `CodexLimitMonitor.exe`.

Portable можно переместить: при следующем запуске приложение автоматически обновит устаревший путь автозапуска.

## Первый запуск

При запуске монитор последовательно ищет Codex CLI:

1. в `CODEX_LIMIT_MONITOR_CODEX_PATH`;
2. в `PATH`;
3. в стандартных папках npm, WinGet, WindowsApps и локальных программ;
4. среди зарегистрированных Windows App Paths.

Если заданный вручную `CODEX_LIMIT_MONITOR_CODEX_PATH` неверен, приложение намеренно не переходит к автоматическому поиску: исправьте или удалите переменную и перезапустите монитор. После подключения состояние HUD меняется на **LIVE**. Значок приложения может находиться среди скрытых значков системного трея.

## Управление и настройки

Через меню значка в трее можно показать или скрыть HUD, обновить данные, открыть диагностику, включить запуск с Windows и завершить приложение. Положение, прозрачность, компактный режим, click-through и прочие параметры сохраняются автоматически.

- настройки: `%LocalAppData%\CodexLimitMonitor\settings.json`;
- журнал: `%LocalAppData%\CodexLimitMonitor\Logs\monitor.jsonl`;
- предыдущий журнал после ротации: `monitor.jsonl.previous`;
- окно диагностики: значок в трее → **Диагностика**.

Автозапуск хранится в пользовательском разделе Windows и не требует прав администратора. Одновременно работает только один экземпляр приложения.

## Обновление

- Setup: запустите новый установщик поверх существующей версии;
- Portable: завершите приложение через меню в трее, замените файлы новой распакованной сборкой и снова запустите его.

Настройки и журналы находятся отдельно от программы и при обычном обновлении сохраняются. Автоматической загрузки обновлений в версии 0.1.0 нет.

## Удаление

Для версии Setup откройте **Параметры Windows → Приложения → Установленные приложения**, найдите Codex Limit Monitor и выберите удаление. Деинсталлятор корректно завершает работающий монитор, удаляет файлы программы, ярлыки и запись автозапуска.

Для Portable выберите **Выход** в меню трея и удалите распакованную папку. Если автозапуск был включён, приложение обычно удалит его при выходе; ручное восстановление описано в руководстве по устранению неполадок.

Настройки и журналы намеренно сохраняются в обоих случаях. Чтобы удалить их отдельно:

```powershell
Remove-Item -LiteralPath "$env:LOCALAPPDATA\CodexLimitMonitor" -Recurse
```

## Сборка и тестирование

Для разработки требуется .NET SDK 10. Для создания Setup дополнительно нужен Inno Setup 6; его можно установить из официального источника WinGet:

```powershell
winget install --id JRSoftware.InnoSetup -e -s winget
```

Полный релизный цикл:

```powershell
dotnet restore .\CodexLimitMonitor.sln
dotnet test .\CodexLimitMonitor.sln -c Release --no-restore
.\scripts\Publish-Portable.ps1 -Version 0.1.0
.\scripts\Build-Installer.ps1 -Version 0.1.0
```

Portable-публикация создаётся в `artifacts\publish\win-x64`, ZIP и его `.sha256` — в `artifacts\release`, установщик и его `.sha256` — в `artifacts\installer`. Скрипты проверяют состав дистрибутива и блокируют известные типы секретов и локальные пути пользовательского профиля.

## Известные ограничения

- версия 0.1.0 выпускается только для Windows x64;
- сборки не подписаны Authenticode, поэтому SmartScreen может показать предупреждение — перед запуском проверьте источник файла и его SHA-256;
- автоматического обновления пока нет;
- изменение протокола Codex App Server может потребовать обновления монитора;
- набор окон лимитов определяется сервером и может различаться между аккаунтами и планами;
- виджет не прогнозирует расход токенов и не управляет reset credits.

Дополнительные сведения: [устранение неполадок](docs/troubleshooting.md) и [заметки о протоколе](docs/protocol-notes.md).
